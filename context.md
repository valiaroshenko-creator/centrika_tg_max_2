# Контекст проекта: лендинг канала «Центрика»

## Что это

Одностраничный сайт-визитка для Telegram/Max-канала компании «Центрика» — про охрану труда, промышленную безопасность и экологию. Канал ведёт фаундер Валерий Ярошенко.

Стек: чистый HTML + CSS, один файл `index.html` + изображения рядом. Без сборщиков, без JS-фреймворков, без зависимостей. Открывается двойным кликом.

Сайт уже собран. Папка проекта: `centrika-site/` (8 файлов).

## Референс

Дизайн взят со страницы **https://asfomicheva.ru/max_anna** (лендинг канала Анны Фомичёвой про ВЭД). Структура почти 1-в-1: автор слева крупно → оффер справа → статы → блок «вы получите» с галочками → две CTA на мессенджеры → промо-баннер. Отличия: тёмно-синяя гамма (у Фомичёвой светлая), без статов «300+ компаний за год».

## Структура секций (по порядку)

1. **Header** — логотип «Центрика» слева, две компактные кнопки Max + Telegram справа
2. **Hero** — двухколоночный
   - Слева: портрет Валерия Ярошенко (4:5, скругл. 28px) + подпись «Валерий Ярошенко» + «фаундер «Центрики»»
   - Справа: кикер-плашка «Устали сами разбираться…» → H1 → lead → две CTA (Max gradient + Telegram blue)
   - На мобильном (≤600px) фото сжимается в круглый аватар 64px и встаёт рядом с именем в одну строку
3. **Stats** — три белые карточки: «18 лет», «1000+ предприятий», «под ключ»
4. **Author + Phone** — слева текст о компании и список услуг с градиентными чек-марками, справа iPhone-макет с главным экраном канала
5. **Benefits** — 4 белые карточки 2×2: Экспертные материалы / Инструменты, кейсы, практика / Разбор ошибок / Интересные факты из истории отрасли
6. **Posts** — два iPhone-макета с реальными скриншотами постов канала (слегка наклонены ±3°, выравниваются на hover)
7. **For-whom** — два карточки: серая «Простым языком» + градиентная «Для кого канал»
8. **Promise** — большой тёмный баннер с обещанием «Подписчики канала быстрее адаптируются…» + повторные CTA
9. **Footer** — логотип + реквизиты компании

## Цветовая система

CSS-переменные в `:root`:

```
--bg: #08182C            (главный фон, тёмно-синий)
--bg-soft: #0E2540       (карточки for-whom)
--bg-elevated: #133258
--bg-deep: #050E1C       (промо-баннер, футер)

--bg-card: #FFFFFF       (белые карточки на тёмном фоне)

--text-light: #FFFFFF
--text-light-muted: #A8C0DC
--text-light-dim: #6F8AAB
--text-dark: #0A2540     (текст на белых карточках)
--text-dark-muted: #4A6585

/* Брендовый градиент — взят с логотипа Центрики */
--accent-blue: #1E8CDB
--accent-cyan: #22BDD9
--accent-teal: #26C5A0

/* Max — сине-фиолетовый градиент под реальный логотип */
--max-c1: #2DBEFF
--max-c2: #5C4FFF
--max-c3: #8B3DD9
--max-shadow: rgba(91, 79, 255, 0.4)

/* Telegram */
--tg-blue: #229ED9
--tg-blue-hover: #1A8BBF
```

Брендовый градиент `blue → cyan → teal` используется как акцент: в названии тем в H1, на цифрах в статах, в чек-марках, на карточке «для кого», на бордерах аватаров, в гирляндах рамок.

## Типографика

- **Заголовки (h1, h2, h3):** `Unbounded` (с Google Fonts), вес 600–800, letter-spacing -0.02em
- **Текст:** `Onest`, веса 400–700
- Оба отлично работают с кириллицей

## Финальный H1 (важно, дорабатывалось много раз)

```html
<h1>
  Канал про <span class="grad">охрану труда,</span> <span class="grad">экологию</span><br>
  и <span class="grad">промбезопасность</span><br>
  для ответственных и руководителей
</h1>
```

— первая строка: «охрану труда, экологию» (оба слова градиентные)
— вторая строка: «и промбезопасность» (промбезопасность градиентное)
— третья строка: «для ответственных и руководителей» (обычным белым, без градиента)

Слово **«промбезопасность»** — намеренно сокращённое, не «промышленная безопасность».

## Что нужно доделать (placeholders в текущей вёрстке)

1. **Реквизиты в футере** — стоит «ООО «Центрика»» и «ОГРН / ИНН — на согласование». Нужны реальные.
2. **Ссылки на каналы** — везде заглушки `https://max.ru/` и `https://t.me/`. Поставить реальные URL каналов в Max и Telegram (6 ссылок в HTML: 2 в шапке, 2 в hero CTA, 2 в нижнем промо).
3. **Статы** — «18 лет» подтверждено пользователем, «1000+ предприятий» — поставлено наугад, нужно реальное число. «100% / под ключ» — обтекаемая формулировка, можно заменить на конкретику.
4. **Список услуг в блоке «Автор канала»** — я написал 4 пункта на свой вкус (аудиты ОТ/ПБ/экологии, сопровождение проверок ГИТ/Ростехнадзора, обучение, закрытие предписаний). Желательно сверить с тем, что реально делает Центрика.
5. **Текст-обещание** во многих секциях я придумывал сам — стоит вычитать на соответствие реальности.

## Адаптив

Брейкпоинты:
- **900px** — hero и author-section схлопываются в одну колонку, benefits и for-whom тоже в одну колонку, фото фаундера остаётся большим но центрируется
- **600px** — фото фаундера превращается в круглый аватар 64px рядом с именем (горизонтальная «author-карточка»), статы в одну колонку, лейблы кнопок в шапке скрываются (остаются только иконки), наклоны постов отменяются

## История работы (что было)

Шли итерациями: сначала мокап в SVG → утвердили → собрали HTML → пользователь добавлял ассеты по одному (логотип, фото фаундера, скриншоты канала) → меняли палитру (сначала розовый Max → сине-фиолетовый под реальный бренд) → правили формулировки заголовка.

Пользователь:
- любит коротко и по делу
- честно говорит «получилось не очень», без церемоний
- просит «без подхалимства», ценит обратную связь по сути
- ходит итерациями маленькими шагами, не «всё сразу»

## Как продолжить в новом чате

1. Прикрепить этот файл `context.md`
2. Прикрепить актуальный `index.html` и все 7 ассетов (или сразу `centrika-site.zip`)
3. Сразу ставить новую задачу — например:
   - «вычитал тексты, поправь блок выгод вот так: …»
   - «появились реальные ссылки на каналы, поставь»
   - «нужен второй экран про услуги Центрики (не канал, а сама компания)»
   - «давай отзывы клиентов добавим перед футером»

Новый Claude должен **сначала открыть `index.html` (через view), посмотреть текущую структуру и переменные**, а потом править через `str_replace`, а не переписывать всё с нуля.
